## Data source note
arvana.gr sits behind a Cloudflare JS challenge, which blocks automated fetching
from the cloud sandbox. The brand/category/USP data above was verified from the
site's publicly indexed pages, brand press coverage, and the store's own listings.
To pull **live product names and prices**, run `tools/arvana-scan/scan-arvana.js`
from a local machine with a real browser (see `README.md`) and fold the output in.
Note: live prices are generally **not** recommended inside RSAs (they change and
can trigger disapprovals), so this copy is complete as-is.
